# Shanmugam Industries

Official corporate web platform for **Shanmugam Industries** — premier manufacturer of automotive body fillers, metal pastes, and surface refinish compounds.

## Key Features

- **Brand Wordmark Preloader**: Letter-by-letter kinetic split animation with pulsing burgundy radiance.
- **Top Announcement Marquee**: Infinite smooth scrolling ticker with contact details, business hours, and ISO badge.
- **Interactive Product Catalog**: High-performance body fillers with pack size selectors and instant quote inquiries.
- **Side-by-Side Product Comparison**: Mobile & desktop optimized comparison table and product difference showcase.
- **Global Compliance & Certifications**: ISO 9001:2015, Export Compliance, and Lab COA analysis documents.
- **Mobile Responsive Design**: Horizontal swipe carousels with magnetic snapping for products and industry sectors.
- **Interactive WhatsApp Support Widget**: Quick-access inquiry chips and direct messaging.

## Tech Stack

- **React 18** with **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React Icons**

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
